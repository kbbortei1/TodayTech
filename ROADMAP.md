# TodayTech Roadmap 🗺️

TodayTech is continually evolving to become the ultimate open-source opportunity radar for builders and students worldwide. Here is what is planned for upcoming milestones.

---

## 🚀 Near-Term Priorities

- [ ] **WhatsApp Bridge:** Connect TodayTech via WhatsApp Cloud API or Baileys so users without Telegram can receive daily digests, check deadlines, and trigger scans directly on WhatsApp.
- [ ] **Calendar (.ics) Sync & Export:** Automatic export of application deadlines to standard `.ics` calendar feeds for Google Calendar, Apple Calendar, and Outlook.
- [ ] **Email Digests:** Support sending clean, styled HTML/Markdown digests directly to personal inboxes via SMTP, SendGrid, or Resend.
- [x] **Web Dashboard:** A lightweight local web interface (built with FastAPI + vanilla HTML/CSS) for visual opportunity tracking, application kanban board, and profile editing. (`todaytech web`)

## 🧠 Intelligence & Pipeline Enhancements

- [ ] **Local LLM Embedding Deduplication:** Vector embeddings using lightweight local models (`sentence-transformers`) for even deeper duplicate semantic clustering.
- [ ] **Interview Prep Module:** Generate sample technical and behavioral interview questions tailored to specific fellowship and internship descriptions.
- [ ] **Resume / CV Diffing:** Recommend specific bullet points or keywords to add to a user's resume for each target opportunity.
